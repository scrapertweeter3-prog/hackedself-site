# hackedself.com

Practical biohacking for longevity: protocols, supplement stacks, and gear reviews,
treated as evidence questions instead of vibes.

What that means in practice:

- **Protocols carry doses.** The sauna-vs-cardio piece answers "can a home sauna
  replace Zone 2?" with a minimum dose (4 sessions above 175 F), not a mood board.
- **Effect sizes over headlines.** The semaglutide review reads the longevity
  evidence as real but narrow, and states the caveat (HIV-patient cohorts, not
  healthy-world trials).
- **Cost math.** Home sauna running cost is computed per session and set against
  the gym sauna lounge, with the break-even point worked out.
- **n=1 caveats stated plainly.** When the evidence is thin, the piece says so.

Live at https://www.hackedself.com/
